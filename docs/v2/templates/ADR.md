# ADR 模板（复制后填写；本文件不是已接受决策）

- **标题 / 编号**：ADR-XXX
- **状态**：PROPOSED / ACCEPTED / SUPERSEDED
- **关联需求**：哪些用户行为、不变量或已验证风险促使决定
- **背景和证据**：当前版本源码、实际问题与约束
- **候选方案**：列出实际考虑的选项以及不选的原因
- **采用的决定**：清楚写明职责边界和生效范围
- **代价与迁移影响**：现有数据、接口、权限、成本、测试、旧 ADR 的处理
- **接受依据**：谁确认、何时生效、怎样验证
- **重新评估触发条件**：什么证据会促使修订

> ADR 不把暂定的 Schema/工具偏好自动升格为永久约束；必要时用新决定明确替代旧决定。
