# TASK 模板（复制后填写；本文件不是活动任务）

- **关联需求**：V2-Rxx
- **任务目标**：一句可观察的结果
- **范围 / 不做**：本次允许改变什么，不改变什么
- **基线与现场**：分支、HEAD、相关未提交文件和外部状态
- **完成条件**：至少一个正例、必要的负例与对应证据；有价/不可逆操作的授权边界
- **相关设计与文件**：引用权威文档和可能受影响的模块
- **执行记录**：只记有意义的决策与版本变化，不复制全部日志
- **结果**：COMPLETE / PARTIAL / BLOCKED，给出运行过的检查及实际结果；未执行就写未执行
- **未闭合风险和下一动作**：一个可执行的下一步及前置条件

> 小修复可仅用 PR；只有需要跨窗口/跨模块交接时才创建独立 Task。任务不能自动扩大用户授权。
