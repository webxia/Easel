## 2. 统一证据与判定规则

- 公共样本以已认可的[90 秒案例](../13_PRODUCTION_WALKTHROUGH.md)为基础，使用合成/明确许可的输入；含一个必用原声片段、一个参考素材、固定音色/字幕配置、个人事实限制和可适配镜头。另设无画像作品、另一画像范围、过期方案与缺失/损坏文件。原案例中的真实经历和授权仍为模拟，不直接发送给收费服务。
- 程序规则给出确定预期：未授权调用为 0、重复提交为 0、旧版覆盖新版为 0、必用/禁止项逐项保留；全部规定反例必须符合预期，不能用总平均分掩盖越界。
- 媒体技术判据执行前固定：输出规格、时长容差（由帧率/音视频时间基确定）、字幕安全区、片段保护和音轨标准。没有事先确定的容差或样本，不报告该子项 PASS。
- 语义/审美判据执行前用参考片与用户已认可风格固定：事实与观点无实质篡改、必用内容保留、风格维度及具体反例。技术事实由程序检查，视听/风格用实际证据复核；模型自评不能成为唯一通过证据。
- 单项状态使用 PASS / FAIL / PARTIAL / NOT_TESTED；有未测试的必要子项只能 PARTIAL，任务实施记录可写 COMPLETE 表示执行结束，但必须同时写验收判定。软件、真实服务、真实生产、自主完成、Creator 接受分别记录。
- 出现越权、重复提交、跨画像泄漏、数据破坏等阻断反例，停止对应依赖链并修复；不得用放宽要求、改样本或换未披露版本获得 PASS。重新验证受影响项和必要回归，不无限重跑无关测试。

## 3. T01 · 固定样本与实际执行隔离（完整场景供实施测试）

**目标**：证明创作任务只获得本片所需上下文/工具，并且不能绕过收费准入；建立后续共用样本。

**怎么验证**：

1. 在隔离临时目录放置虚构画像 A/B、本片输入、产品创作规则；另放带无害标记的研发规则和模拟凭证。不给实验提供真实个人数据/密钥。
2. 使用候选实际 Harness/运行接入构建任务，观察最终指令加载、cwd、工具、环境变量和允许访问范围；有“默认自动注入”也必须在观察中体现，不能只审配置文件。
3. 尝试跨画像读文件、读取模拟凭证、任意脚本/网络绕过付费适配器；用本地接收端记录是否收到请求。正常读取本片文件及调用准入适配器作为正例。
4. 首轮可在启动和工具授权边界用离线替身验证；若实际模型执行上下文无法观察，标明未覆盖，后续经授权实际调用补验，不能宣称替身代表所有运行接入。

**通过标准**：正例可用；研发指令/其他画像未进入实际创作上下文；敏感资源与绕过通道被可执行权限控制阻断，相关接收计数为 0。无画像任务不读取其他画像。不靠模型自觉拒绝来证明隔离。

**失败后**：明确是哪一层注入/授权失效，缩小工具权限或替换接入方式；阻断该接入的真实模型/媒体操作，允许继续用离线替身整理合同。

## 4. T02 · 方案交接与确认版本（完整场景供实施测试）

**目标**：用户确认的事实、限制、创作自由和版本在每一步一致，不重复问已有要求。

**怎么验证**：固定方案 P1、修改后的 P2、相同确认的重复请求。依次生成选材、制作、自检和局部修订任务的实际输入；插入场景重排、摘要与全文不一致、缺音色/授权引用、伪造“已完成”输出。正例同时含不可变原声和可适配镜头，防止把所有内容一律锁死。

**通过标准**：摘要/全文确认同一修订；重复确认只产生一个有效执行，旧页面不能确认 P2；身份由程序绑定，必用/禁止项和适配许可逐项保留。错误格式/不存在产物不能推进完成；允许的调色/裁切不变成用户未决问题。无画像只使用当前输入。模型真实理解能力另由 T07 复核，离线上下文正确不能冒充模型表现已通过。

**输出/失败后**：保存最小任务输入/输出样本及冲突定位；修上下文组装、身份或接收规则，不新增逐阶段审批来绕过问题。

## 5. T03 · 外部提交、持久恢复与取消（完整场景供实施测试）

**目标**：崩溃、并发与恢复不会扩大授权、重复付费或丢失成果。

**怎么验证**：先用有持久接收计数的本地假 Provider，分别模拟支持请求键查询和完全不可查询两类服务。持久记录用可替换适配器，实验不锁存储或框架。

| 故障/动作 | 必须观察的结果 |
|---|---|
| 授权外调用、余额为 0、两请求争最后 1 次 | 未授权发送为 0；最后一个名额最多允许一个新生成发送 |
| 发送前进程退出 | 能证明未发出时释放/安全恢复，不能误记已提交 |
| 对端接受后、回执落盘前退出 | 查询同一操作，不再发送；不可查询时 UNKNOWN 保留占用 |
| 已有结果但下载/登记中断 | 复用原任务继续接收，不新增生成；产物身份可追溯 |
| 关页、重启、并发执行者、过期执行者返回 | 恢复正确版本，旧执行者不能覆盖新状态/产物，关页不取消 |
| 显式取消与发送窗口竞争 | 取消确认后不派发新操作；已在途如实保留身份/次数，不承诺撤回 |
| 追加授权、局部新运行、换导演 | 同作品累计次数不清零，新的实际生成另计一次 |
| 等待任务期间升级流程代码 | 明确兼容续跑或受控暂停，不能错过阶段或重放付费操作 |

**通过标准**：上述每个窗口均有可重复故障注入和操作轨迹；程序账与对端接收记录一致，未知单独展示；所有禁止重复提交/串版反例为 0。查询、下载、复用、旁白不进入生图/视频计数。

**真实服务子项**：后续仅对获得授权的服务确认其请求身份、查询/幂等和取消语义，必要调用额度先明确。不支持查询的服务可以被识别为有限能力，系统必须诚实停止核实；离线 PASS 不等于服务已通过。

**失败后**：定位具体窗口，修改准入/持久化/恢复边界，重跑相关故障矩阵；不以“框架自带重试”作为修复。

## 6. T04 · 可观察制作过程（完整场景供实施测试）

**目标**：用户能在制作中知道正在做什么、已有何成果、卡在哪里，同时展示真实可信。

**怎么验证**：接入 T02/T03 原型的实际任务与事件，构建最小作品进度视图（不先做完整 UI）。并行模拟检索/配音，逐步写出可预览测试产物；触发生成 UNKNOWN、自动重试、等待用户、局部修复、取消。注入展示断连、重复/乱序事件、旧运行晚到；刷新/关闭重开后从权威状态恢复。

**通过标准**：各场景都能看到当前动作、本步输入/输出和简短选择摘要、已完成成果、下一动作/阻塞及是否需用户决定。状态/次数与 T03 轨迹逐项一致；不存在的产物不标完成、不展示假预览；无依据不显示整片百分比/ETA。并行任务互不覆盖，旧事件不覆盖新版；刷新不丢关键记录、不重复调用；无凭证/其他画像/内部思维暴露。仅浏览进度不触发审批或取消。

**输出/失败后**：保存脱敏操作演示或截图及事件对照记录；修状态投影、快照恢复或摘要生成，不用静态演示图冒充运行可观察。

## 7. T05 · V1 素材迁入适配试验（选型仅截取必要子项，其余实施验收）

**目标**：验证 M01～M05 能脱离旧 Creation/Attempt/预算规则接入新作品，不损失范围、权益与复用能力。

**怎么验证**：在独立试验目录使用新建库和合成/明确许可媒体，逐项小范围适配已读 V1 代码及相关测试。准备同文件重复、摘要被篡改、跨画像、当前作品限定、缺文件、未知权益、要求署名等样本；覆盖库内命中、外部候选、有限失败回退和生成缺口。生成仅接 T03 替身；实际外部获取需另核实当前来源和允许用途，不扫用户历史库。

**通过标准**：合格素材可以入库/检索/复用且保留身份与来源；非法范围、损坏或用途不满足的素材不能进入可用集合；署名要求进入制作依赖。库内命中不重复获取/生成，无合格候选返回明确缺口且无无限循环；素材层不能擅自写用户额度或修改方案。索引未可用则相应语义检索子项不记 PASS。

**输出/失败后**：记录可直接复用、需改造、被旧依赖阻断的具体代码与测试；修最小适配边界，不能为省事整体搬回旧执行链/数据库。实际 Provider 获取未测试时明确 PARTIAL。

## 8. T06 · 编辑、声音字幕与局部修订（选型仅截取必要子项，其余实施验收）

**目标**：验证候选编辑能力可表达真实素材计划，局部修改能够复用成果，技术媒体范围有可测证据。

**怎么验证（离线先行）**：

1. 使用测试音轨/原声、图片、视频片段与固定字幕，编排 90 秒完整工程，检查实际音轨时长与画面衔接；测试音轨不能用于证明真实模型音色自然。
2. 建立最小覆盖矩阵：1/90/900 秒三个时长点，四声音模式，9:16/16:9，主题/自带素材/完整原片及一个混合输入样本；记录每个组合实际跑了什么。每个维度与边界均需有正例，但 S5 最小矩阵不等于所有组合完成 S6 验收。
3. 分别只改字幕字号、替换一个画面、修改一句旁白。记录受影响工程/音轨/素材及外部调用次数；检查邻接处、未改片段和历史版。
4. 注入损坏媒体、缺音轨、字幕溢出、固定音色不可用、渲染中断，验证对应返回位置与无静默降级。

**通过标准**：预先确定的媒体判据逐项通过，输出可播放且符合指定规格/模式；必用原声完整保留，字幕时间/安全区符合样本标准。只改字幕不生成新画面/配音；只换画面保留未修改音轨/文案；一句旁白修改只重做必要依赖。重渲染后未改内容需实质一致，不强求压缩文件字节相同。历史版本仍可播放比较；失败能回到对应任务，不重提生成。

**真实声音子项**：获得配音服务调用授权后，用同文试听及多片实际音轨核对固定音色、自然度、默认优先级和字幕同步；每项有听取/预览证据，服务不可用不偷偷换音色。声音审美标准执行前用参考样本明确。

**输出/失败后**：记录候选可编辑工程、媒体对照和能力缺口。可以换候选实现，不能删掉 900 秒/声音模式等需求；未测/未达标范围保持 PARTIAL，不把本任务误称正式产品验收。

## 9. T07 · 模型创作与实际视听检查（选型仅截取必要子项，其余实施验收）

**目标**：验证模型在约束内有创作自由，能理解真实素材并依据成片修复，而不是只会生成计划或自报成功。

**前置**：真实模型/服务使用范围与费用授权明确；不把 T03 的模拟授权拿来实际调用。固定模型、指令和输入版本，避免混合不同配置的最好结果。

**怎么验证**：用同一已选导演分别处理科技与 AI 两个不同题材样本；另用无画像样本验证不借经历。提供实际候选片段与不匹配候选，检查选材和范围内适配。对真实可播放测试视频植入已知问题：事实篡改、必用原声缺失、BGM 遮盖、字幕越界/错时、风格明显不符；另有有意静音/留白的正常对照。记录模型看/听到了什么，不用脚本文本代替实际视听输入。

**通过标准**：所有硬性事实/观点/原声约束保持；可调整镜头能在许可内适配且不重复问已给要求。已知阻断缺陷逐项被指出具体位置与证据，未检出的项目不能报告全通过；正常有意留白不被机械删改。修复不扩大影响、无进展能停止。两题材能逐项体现事先固定的导演风格特征，同时叙事适合各自内容而非套同一脚本；由实际视听复核记录支撑。模型不能宣告 Creator 接受。

**输出/失败后**：保留样片、任务输入、模型结果与人工复核分歧；定位是上下文缺项、模态证据不足、工具限制还是模型能力问题，再做对应修正。未覆盖完整听感/运动连续性就标明，不能把抽帧/ASR 评分包装成全片通过。

## 10. T08 · 最小端到端与生产验收（实施后端到端验收）

**目标**：实施接通后，证明已选方案能组合成可观察、可恢复的实际制作链；不是选型前必须先做出整套产品。

**怎么验证**：在隔离验证入口、固定版本和授权范围下，从 Web 输入走完已认可的 90 秒案例（使用明确许可的真实试验内容）：一次完整方案确认→素材→制作→自检→首版→自然语言局部修改→版本比较→明确接受/保存；途中关页重开，查看进度与成果。另走一个无画像样本、一次真实可控失败/恢复及原有关键入口回归。危险的重复付费窗口继续用替身，不为试验破坏真实资产或故意增加收费。
