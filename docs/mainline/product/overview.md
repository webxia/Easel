# Easel 产品定位

状态：**CURRENT — 产品定位**。来源：V2 已确认的产品目标；实现进度另见 [当前状态](../project/status.md)。

## 核心命题

**一个 Creator / Profile + 一个 Director / Creative Mode + 不同 Content，持续输出风格辨识度稳定、内容表达不被模板锁死的视频。**

- **Creator**：谁在表达，拥有事实、身份、受保护要求、委托与最终审阅决定。
- **Content**：这次要表达的主题和内容，每条作品不同。
- **Director / Creative Mode**：怎样表达，稳定叙事、镜头、声音、节奏与视觉语言，但允许合理创作选择。
- **Creation**：一次可追溯的作品生产，不等同于 Agent 会话或一个固定模板。

## V2 当前闭环

从 Web 讨论和修改创作方案开始；Creator 明确确认内容、风格、硬要求、可适配范围及必要授权；系统在范围内尽可能自主形成场景计划、合法素材、导演选择与实际视频；经技术和质量检查后交付 **可审阅首版**；Creator 可以接受、反馈或要求局部修改。

只依赖截图、Prompt、模型回答、规划 PASS 或空文件，均不算完成视频。

## 产品边界

- 当前优先视频，不把发布、社媒分析、多导演经营、跨作品历史经验库作为首版建设前置。
- 四种声音模式（静音、音乐、旁白、旁白+BGM）与 **1～900 秒**是保留的产品需求。45 秒只是早期端到端样本，不缩减正式范围。
- 真实素材可能不完美：导演可以在用户许可内选择替代，不能静默更改核心内容、事实、锁定镜头和授权。
- Rights、成本与不确定外部操作需要清晰可验证的边界；不自动发布，不以创作效率绕过合法性。
- 优先复用官方 Easel 的可靠能力；不自动继承旧 `easel-studio` 的内部协议与补丁。

## 成功的三个层次

1. **技术可用**：代码与离线集成在当前版本通过相应验证。
2. **真实生产可用**：真实模型、素材和制作路径产生可播放、可审阅、留有来源与执行证据的视频。
3. **Creator 接受**：Creator 对作品质量作出接受或反馈决定。

这三者的证据不可互相替代；是否达到 V2 目标由真实作品和用户体验共同决定。
