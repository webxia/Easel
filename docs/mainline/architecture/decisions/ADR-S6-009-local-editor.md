# ADR-S6-009 · 首个实际编辑后端采用本地 FFmpeg 时间线

- **状态**：IMPLEMENTED — S6-09 范围内已实现并通过本机媒体测试；不是全部编辑能力或正式作品验收。
- **日期**：2026-10-17。
- **关联需求**：V2-EXP-009、015、022、025；配合 007、010 的原声和局部修改保护。
- **接受依据**：用户已授权 S6 业务研发及任务内技术落实；本决定落实 S6-09 的条件接入分支，不改变已确认产品目标，也不宣称用户单独接受了最终视听效果。

## 证据与取舍

本机已安装 FFmpeg/ffprobe **8.1**，macOS arm64，FFmpeg 由 Apple clang 16.0.0 构建；`ffmpeg -L` 报告本构建为 **GPLv3 或后续版本**，含 libx264。代码调用用户已有外部程序，不把其二进制加入仓库；若后续分发二进制，按实际构建核对许可证和对应源代码义务。[FFmpeg 官方许可说明](https://ffmpeg.org/legal.html)。本实现检测必要滤镜与编码器，不把版本号单独当作可用性证明。

已装 Hypit 为 **0.2.7**。其包内许可证是附加条件的 Apache 2.0 文本，包含商业分发、托管等限制；因此不将它描述为无条件可分发依赖。V1 `native_source.py` 绑定内部源码摘要及 darwin-arm64 组件；CLI 保留 HOME、可能接触 Runtime CredentialStore。当前没有建立其纯制作隔离适配，未调用 Hypit、修改 Runtime 或安装依赖。**这表明当前接入证据不足，不表明 Hypit 本身不能纯制作。**

Remotion 仍可在需要代码图形能力时评估。当前先选已可执行的 FFmpeg 后端，将进程、素材与收费通道分开；不搬 V1 Delivery、Hypit 旧 parser 或原片 SDK 的品牌/审批/风格规则。

## 实际边界与接口

`easel.production.editors` 导出 `FFmpegEditor`、`EditProject`、`AssetManifest`、`MediaAsset`、`Scene`、`AudioClip`、`Caption`。公共操作为 `capabilities/check/build/observe/cancel/collect`；`build(..., job_id=...)` 持久登记并启动独立本地进程，重复身份绑定同一输入。工程 JSON、稳定场景身份、来源摘要、渲染记录与结果摘要保留在专用任务根。

应用负责构造素材清单，模型只引用 asset_id。素材必须是清单根内的真实本地文件，路径、符号链接、扩展名和摘要均校验后复制到任务内。FFmpeg/ffprobe 只允许 file/pipe 协议；过滤器由类型化参数编译，禁止任意表达式、代码和 URI。子进程无媒体 Provider 凭证，使用独立 HOME，无法从此接口请求生成。

这个时间线属于 **FFmpeg 后端自己的编辑表达**，不是要求其他引擎服从的新通用 DSL。现有短视频合成器的默认补帧、字幕回退、配音推导、漏音效和非零音量回退均未直接沿用。真实视频可剪辑、裁切、拼接和溶解；图片运动只用于明确选定的图片，不替代要求视频的场景。原声与独立音轨分别处理；只有明确的音乐/音效 loop 才循环，视频或旁白不足直接报错。

本机构建缺少 libass/drawtext，字幕以已有 Pillow **12.3.0** 和明确字体资产渲染为透明图层再叠加，支持中文、字号、位置、颜色、描边、背景和关闭；不默换字体或缩小溢出文字。参数生成的裁切、混音等使用 FFmpeg 公共滤镜；所有媒体输入是本地资产。[滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)、[协议白名单文档](https://ffmpeg.org/ffmpeg-protocols.html)。

## 具名能力矩阵

| 能力 | 本次实际证据 | 仍不证明 |
|---|---|---|
| 四声音模式 | 1 秒合成测试分别验证无音轨静音、音乐、原声、原声加音乐；零音量保持零 | 真实旁白自然度、配乐审美 |
| 两画幅 | 1080×1920、1920×1080 MP4 实际解码/规格检查 | 4K、1:1 或所有编码格式 |
| 时间与镜头 | 1 秒及 900 秒实际编码；原片截取、视频溶解、明确图片推拉/淡入 | 所有时长×声音×输入的笛卡尔积 |
| 字幕/局部修订 | 实际中英文字幕、背景、字号与裁切修改；导出 AAC 字节完全一致，复用一个音频缓存 | 真实题材导演风格、所有文字排版质量 |
| 观察与恢复 | 持久 job/阶段；新 adapter 查看既有任务；取消；释放锁后恢复已中断本地任务 | 所有 OS 杀进程、断电场景 |
| 素材安全 | 摘要篡改、路径越界、URI、符号链接、过期 job 输入拒绝 | 用户主动修改受信任程序/系统后的安全性 |
| 平台 | 当前 macOS arm64 真实通过 | Ubuntu/Windows 尚未运行，不报通过 |

后端声明最多 128 个场景、24/25/30 fps。任意代码、3D、自定义 shader 等不受支持；模型必须按 capabilities 规划，已确认方案需要缺失能力时返回 `capability_unavailable`，不能自动替换为简单幻灯片。质量服务仍需检查真实成片，`completed` 仅表示本地渲染完成，不等于可审阅首版或 Creator 接受。

## 恢复、影响与重新评估

原声/配音混音按输入和实际声音设置缓存，字幕/裁切修改复用同一编码音轨。取消是持久请求，运行进程观察后停止；完成与取消有共同终态锁。重启通过 OS 文件锁识别失去执行者的任务；恢复只重渲染本地文件，使用唯一临时文件防止已崩溃执行者留下的编码子进程覆盖新尝试结果。硬杀 Python 时可能仍有短暂本地编码残留，不能据此宣称系统级进程隔离或所有中断都已覆盖。

当正式方案需要当前后端不能表达的效果、平台滤镜不可用、复杂长片性能不足，或 Hypit/Remotion 的公共接入与隔离证据完备时重新评估。保留已制作资产和版本，不因换引擎重复生成。主线适配、真实题材质量与完整范围验收由后续集成及 S6-14 对应阶段完成。
