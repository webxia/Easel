# 自然定长与图解呈现衔接方案

状态：**首批收窄范围已授权实施：基础排版与美观；不做复杂动态视图。** 日期：2026-10-24。

最初仅方案授权；用户随后明确要求按收窄方案实施、离线测试后部署。首批复用原生图解数据和Pillow渲染器，调整分组标题对齐、列间距、卡片内边距、弱化边框、柔和高亮与字幕留白；版本标识更新以隔离新缓存，不覆盖既有成片素材。实际成片修订、付费生成和发布不在本轮授权内。

## 1. 目标与定位

让已确认的创作意图准确进入制作：自然定长不因加入BGM而变成固定片长；图解能以完整、可读的布局表达关系及重点，不依赖裁切整张文字图片制造特写。

这是既有视频管线的修复设计，复用一个频道、一个导演，以及当前方案、图解、素材、剪辑和修订机制。不新增审核Agent、审核步骤、评分或统一时长上限，不针对本片频道、导演或文案写特殊逻辑。

关联职责与约束见[领域架构](domain.md)、[实施合同](contracts.md)；实施与验证遵循[工程规范](../development/engineering.md)和[E2E规范](../development/testing.md)。本文区分首批实现与后续候选，不覆盖现行合同。

## 2. 已确认根因与证据边界

受查基线：`easel-v2-rebuild`，HEAD `6084b4ca`，含此前已存在且已部署的工作区修复。原始回执和媒体留本机，不将用户内容和运行身份复制进仓库。

### 2.1 自然定长被旧代码覆盖

1. 原规划模型实际返回 `narration_policy.duration_mode=voice_driven`，摘要说明330秒仅为预算。
2. 原Work没有显式 `duration_seconds` 设置。
3. `6084b4ca` 之前的规划落库逻辑将 `audio_mode != voice` 作为强制fixed条件。本片为mixed，因此将正确的模型策略改成fixed，但摘要未同步变化。
4. 冻结方案实际为fixed/330秒。真实旁白长262.728秒，0.2秒开始；剪辑收到“保持固定总时长”的执行上下文，安排263.2～330秒的66.8秒音乐和尾段画面。
5. `6084b4ca` 已删除mixed强制fixed分支，并调整自然时长预算和音效定位。本片冻结于旧逻辑，后续局部修订沿用该方案，修代码没有追溯修改作品。

结论：主要故障在**模型结果到冻结方案的程序转换**，不能归为模型没有选择自然定长。长尾画面是错误固定时长输入下的剪辑选择；“留白有叙事用途”的提示没有消除上游矛盾。此前字幕和回传修复不包含时长修订。

### 2.2 图解结构没有充分延续到剪辑

- 当前 `ExplainerBoard` 已有栏目、卡片、状态及高亮，`boards.render_board` 按状态输出整张PNG；供料保留board_id、state索引和场景映射。
- 当前剪辑接收图片及这些引用，可用普通crop选择景别；没有供剪辑调用的“按所选栏目/卡片重新排版”呈现方式。结构仍可从冻结方案读取，并非数据完全丢失，但没有形成确定性的布局操作。
- 本片同一图解在正文连续出现54.3秒，尾部另回看20.4秒；正文采用全景和局部裁切切换。抽取第2版实际画面可见邻栏残字、截断的边框和失去栏目标题的局部画面。
- 上轮指定修订只移动一个镜头裁切框以避开字幕，没有重排图解。既有图解校验保护状态存在及顺序，不证明所有景别都表达清楚；技术或抽样检查通过不等于完整剪辑质量通过。

结论：对照图的内容规划本身有用途；缺口在**图解呈现能力与剪辑的连接**，并伴随模型对重复停留的选择不佳。不能以“每张图最多几秒”或“禁止全部特写”代替修复。

## 3. 设计A：时长意图贯穿现有管线

### 3.1 唯一执行依据与已有修复复用

继续使用现有 `narration_policy` 和 `settings.duration_seconds`，不新增第二套时长字段或自然语言关键词分类器。

- fixed：秒数为已确认的精确要求。保持现有时长与原声保护，不因旁白短就自动缩短。
- voice_driven：秒数为方案估计；由现有 `measured_execution_plan` 根据完整配音实测生成执行时长，并使用当前自然收尾安排。BGM时长、普通图解镜头和场景音效跟随执行时间线，不反向拉长成片以凑预算。
- 是否选择自然定长仍由创作Agent理解用户意图并结构化表达；程序只处理已登记的明确设置、原声及绝对时间事件等确定性边界。
- 不重复实现 `6084b4ca` 已有修复。先核对模型响应、冻结结果、实际剪辑请求三者，再针对未覆盖的具体缺口修改。

### 3.2 方案交付说明

复用现有方案上下文与交付回复，以**最终冻结的结构化策略**说明“预计时长”或“固定时长”。不能将生成前摘要中的预算包装成用户硬要求，也不能在执行fixed时仍承诺按旁白定长。

不新增确认页或额外审核；沿原完整方案确认环节表达。若程序因真实硬约束不能保留模型策略，说明实际约束及变化；只有改变用户已确认目标时才走原有决策路径，不能静默覆盖。

### 3.3 固定片长的边界

本次不试图消灭所有无旁白段，也不新增尾段长度阈值。明确固定时长的作品仍允许有内容目的的音乐段、动作或阅读段。只有“估计被错误当成固定要求”的场景属于本次确定修复范围。

## 4. 设计B：先改善现有图解排版与美观

### 4.1 收窄后的首批范围

复用 `BoardCard / BoardColumn / BoardState`、`boards.render_board`、现有供料登记和FFmpeg。首批只调整原生图解的基础排版、样式和剪辑使用指导，不新增overview/focus协议、任意选卡片视图、剪辑中派生图生成器、动画引擎或生产阶段。此前提出的复杂重点视图不进入本次工作包。

- **文字层级**：区分标题、栏目、卡片正文和来源/概念标识；处理长短文字混排，不靠把正文一律放大或缩小解决。
- **形状与颜色**：减少重复厚边框及密集表格感，使用克制背景、对齐和必要高亮；首批在原渲染器内形成一个一致的基础样式，不建多主题配置系统或频道特例。
- **空间**：改善边距、栏间距、内容密度和留白，依据最终画幅及既有字幕排版信息留字幕区域，不把另一套字幕规则写进图解。
- **重点表达**：沿用已确认状态与高亮，默认以可读完整布局呈现关系。普通图片crop能力保留，但不让模型主要依赖裁切文字图制造重点，避免残字、截边及栏目关系消失。
- **节奏**：图解用于解释对应观点，允许穿插相关实拍，不能为补预算反复回看；不设固定停留秒数、重复次数或新审核。

### 4.2 原链路接入与实现边界

仍在原图解供料阶段绘制每个已确认状态，按现有素材身份、版本、字体与画幅生成并登记。样式变更需纳入现有renderer版本/缓存键，不覆盖旧成片或旧图片。首批不扩展持久EditProject合同，也不在剪辑阶段复制第二套图片生产逻辑。

生成优先：通过基础排版和剪辑输入减少对裁切的依赖；用真实图片及短片段检查实际结果，不以提示词替代排版验证。若以后出现现有状态/高亮确实无法表达的具体需求，再单独评估有限重点重排，不把该扩展默认为首批任务。

### 4.3 图解、搜索素材与文生图：当前实际选择路径

只读依据：[规划](../../../easel/production/planning.py)、[素材意图](../../../easel/production/material_intent.py)、[供料](../../../easel/production/supply_tasks.py)。

1. 规划Agent根据内容、导演和本地能力选择是否定义 `explainer_boards`；原生图解当前主要是栏目/卡片/状态式概念图，不等于任意科学图表或数据可视化工具。
2. 方案确认后，素材意图将已定义图解状态映射到场景；供料先用Pillow本地绘图并登记，不消耗IMAGE生成额度。规划等模型调用仍可能产生模型费用，不能把“图解不占生图额度”说成全流程免费。
3. 已有图解素材覆盖的场景，初始供料通常不再为其检索同类画面；其他场景按现有必用输入、素材库和外部来源获取候选。
4. 在普通自动供料路径中，仍有缺口才由现有 `SupplyDecision` 提出IMAGE/VIDEO生成请求；仅向模型提供本片已获授权、可用且有使用依据的生成能力，操作服务继续核对次数、身份和预算。源码另支持已保存/显式给出的生成请求，不能因此宣称任意新方案都已支持自由选择“直接生图优先”。
5. 最终剪辑选择候选是否合适；初始供料的“有素材”不等于语义适用或美观通过。图解难看目前不会自动触发文生图替换。

现有机制是“规划确定图解表达，供料搜索／授权补料”，不是每个镜头在图解和生图之间进行一轮评分竞赛。本次不增加路由Agent、评分或新付费选择流程。

### 4.4 收敛后的选择原则（生成指导，不新增硬门槛）

| 表达需要 | 适合的路径 | 边界 |
|---|---|---|
| 精确中文、分组、比较、卡片状态关系 | 现有原生图解 | 文字与关系来自结构化方案，先改善排版；不把不支持的复杂图表硬塞成卡片 |
| 真实人物动作、现场、操作过程或史料证据 | 合法搜索素材／用户提供资料 | 生成插画不能冒充事实影像，字幕也不能把示意变成证据 |
| 氛围、概念隐喻、无须逐字准确的示意插画 | 适合时考虑文生图，走现有授权生成路径 | 首批仍尊重实际供料能力；不能声称已实现任意场景主动生成优先。已授权是可使用，不是必须使用 |
| 同一段既需要场景也需要精确解释 | 原有多个镜头或图解状态配合 | 不把一段内容全变成文字板，也不新增“生成背景+动态卡片合成”系统 |

不能用“图解便宜”压过表达需要，也不能为美观把准确关系换成不可控的生成文字。若已冻结图解确需改成另一种表达，走现有修订范围和授权，不静默替换。这次对选择方式的工作限于澄清既有能力和生成指导，不扩大生成优先级架构。

## 7. 验收设计

### 软件验收

- 同一模型方案在voice和mixed模式下，均保持voice_driven；实测旁白短于预算时，执行长度随旁白生成，BGM与场景音效不补满原预算。
- 用户明确固定片长、必用原声、绝对时间音效的原有保护不被放宽；不能通过改变声音模式偷偷更改时长。
- 历史冻结fixed作品在普通恢复及字幕局部修订中保持不变；代码升级不自动改片。
- 基础图解保持冻结内容；横竖屏、长卡片文字、多栏目、高亮和字幕同时出现时，整卡及归属可读，没有邻栏残字。用真实排版图片和FFmpeg小片段比较层级、密度、留白与样式，不以不越界或单测通过代替美观结论。
- 无效或跨作品图解引用由既有结构／身份校验拒绝，进入现有错误与修正路径，不新建审核。
- 原图解重复供料、恢复和局部修订保持幂等；不额外调用素材检索、TTS或生图服务；成片回传仍复用已有持久订阅。
- 不以全部清除crop、强制每图固定停留或增加语义审核次数让测试通过。

### 真实效果验收（本轮NOT_TESTED）

经另行授权后，选一个包含BGM、自然定长和对照图的实际样本；核对模型回执、冻结策略、实测声音与最终时间线。观看图解完整段及结尾，确认没有凑预算的长尾和破坏阅读的裁切。按既有检查范围报告技术、抽帧、完整语义／声音与Creator接受，不合并为一个PASS。
