# TASK 模板（复制后填写；本文件不是活动任务）

- **关联需求**：既有 V2-EXP-xxx（保留稳定编号）
- **任务目标**：一句可观察的结果
- **范围 / 不做**：本次允许改变什么，不改变什么
- **基线与现场**：分支、HEAD、相关未提交文件和外部状态
- **完成条件**：至少一个正例、必要的负例与对应证据；有价/不可逆操作的授权边界
- **相关设计与文件**：引用权威文档和可能受影响的模块
- **执行记录**：只记有意义的决策与版本变化，不复制全部日志
- **结果**：COMPLETE / PARTIAL / BLOCKED，给出运行过的检查及实际结果；未执行就写未执行
- **未闭合风险和下一动作**：一个可执行的下一步及前置条件

- **父任务与剩余验收**：如有父任务，写明本项完成后仍需完成什么；真实运行链接对应轮次的唯一检查点，不复制私有回执。

Bug归属与原场景回接按[工程§2.2](../engineering.md#22-复用现有-task调试发现-bug-后回到开发规范)，接手/交付按[任务衔接](../task-handoff.md)，真实恢复按[E2E规范](../testing.md)。执行记录承接预期与实际、首个失败证据、根因或假设、方案取舍及实际回归；不额外引入机器JSON契约或固定修复轮数。
