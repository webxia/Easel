#### 已确定的实现问题与已有机制

1. **停顿精度缺口成立。** [NarrationPause](../../../../easel/production/contracts.py)允许seconds=0.123，[compile_pauses](../../../../easel/production/prosody.py)实际输出`你好<#0.123#>世界`；[MiniMax官方接口](https://platform.minimax.io/docs/api-reference/speech-t2a-http)要求最多两位小数。协议格式问题无需先证明听感变差；改变位置/数量则必须有听感或明确创作依据。后续只在现有合同与编译位置处理新输入，不静默改写已冻结停顿、旧声学请求、回执或缓存；拒绝/规范化方式在实施前明确。
2. **字幕不是从零建设。** [适配器](../../../../easel/production/providers/minimax_speech.py)已有字幕下载与只读补取，[speech_alignment](../../../../easel/production/speech_alignment.py)已有可选本地强制对齐，但依赖有效Provider分段锚点；[aligned_captions](../../../../easel/production/narration.py)已有原文一致性与时间线映射。[single_line_captions](../../../../easel/production/subtitles.py)仅对超宽字幕按字符比例拆分。官方word能力存在，现有请求未发送subtitle_type，解析仅保留段级text/start/end；不能只加请求参数就宣称词级接入。
3. **未来词级接线必须覆盖现有优先级。** aligned_captions目前优先成功的local_alignment，再取provider_alignment；如接入Provider词级数据，应明确精度/来源选择及分组、拆行时原始锚点传递，不能又被本地估算或字符比例覆盖。缺失或文本不匹配保持原路径并披露精度，不以未知强制重配音。
4. **字幕失败保留配音已经实现。** 适配器保留音频并返回alignment unavailable，已有测试覆盖；后续是保护回归，不另建恢复器。成功/UNKNOWN仍按原Operation处理，不因字幕失败重复付费。
5. **声学请求身份需要守住。** [VoiceService](../../../../easel/production/voice.py)已有声音/内部请求/config等缓存身份；最终_wire_request不天然等于内部请求。若仅在wire硬编码新参数，内部身份可能不变。新增能力须明确进入现有请求身份或实现/配置版本，禁止同缓存键对应不同实际请求，不强制旧作品重配音。
6. **淡出属于具体工程选择。** [creation](../../../../easel/production/creation.py)保护完整素材、时长、起点及正增益；[FFmpeg](../../../../easel/production/editors/ffmpeg.py)执行工程fade参数，无此链路全局atempo。片段完整不证明可听性，但不据0.4秒淡出认定吞尾音，也不设所有旁白零淡出的统一规则。
7. **fluent支持暂不确证。** 本次读取[中文官方接口Markdown](https://platform.minimax.cn/docs/api-reference/speech-t2a-http.md)仍说明fluent/whisper仅对2.6生效，另有2.8不支持whisper的表述；不能据此反推2.8支持fluent。现有2.6白名单不定性为Bug，需明确对应模型说明或另行授权验证。未传emotion不表示模型没有自动情绪；不将calm设为通用默认值。
