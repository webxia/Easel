- **当前阶段**：V2.1整体设计与任务建档完成，细化设计待审阅；开发未授权。
- **执行决定**：2026-10-24用户要求“整体设计、一次性实现，完成后统一调试验收，先不改代码，把任务整体建好”。该决定替代先P1验证、再决定P2的排程；P1及P2全部纳入版本工作包。开发基础测试贯穿实现，整体质量调试在完整实现后进行。
- **授权与停止点**：本轮仅调查、方案和仓库任务文档。未授权代码、分支/工作树创建、部署、模型/媒体调用、恢复制作、软件版本发布或视频发布。未来获准后，同一范围内连续完成实现和调试修复，不按工作包重复请示；部署、费用及外部动作核对实际授权。
- **范围**：方案§1.1及§9工作包：依据融合、确定性任务视图、文稿与场景/剪辑表达、事实与观察边界、现有反馈接线、兼容恢复、统一调试、版本交付。
- **不做**：新产品/数据库/状态机、新Agent或审核循环、固定拆分生成、新事实平台、新服务接入、自动长期学习、无关发布或内容库重构。
- **基线与现场**：本轮规划核对`easel-v2-rebuild / 5f1c6d3a206c8faa40344762f6c8d3346005ec35`，有S6-14A等源码/测试/文档Dirty和私人未跟踪资料。状态页已更新到纯视觉局部输出与JSON提示修复交付；本任务不覆盖这些变化、不承接其他任务的部署授权。开发前重新固定含必要Dirty的基线，不能仅按裸HEAD另起实现。
- **设计唯一正文**：[V2.1完整版本规划](../../architecture/creative-context-expression-proposal.md)。本卡唯一维护版本执行状态；现行[职责](../../architecture/domain.md)和[合同](../../architecture/contracts.md)尚未因本方案改写。

## 统一验收矩阵

| 验收项 | 正例/反例与证据要求 | 当前结论 |
|---|---|---|
| 创作依据与设置 | 一句问题能展开；完整六维/频道/导演进入并体现具体选择；换导演不改真实经历/固定音色，无画像不借用他人资料 | NOT_TESTED |
| 输入精简 | 相同作用域重复可折叠；图解状态、SFX窗口、原声/权益限制和观察等级不丢；报告字符与真实Token不同口径 | NOT_TESTED |
| 身份与恢复 | 源记录不变，旧素材意图可兼容；成功回执复用，在途/UNKNOWN不重发；新视图不绕过请求身份 | NOT_TESTED |
| 文稿自然表达 | 保留事实、四条依据及条件；不只去编号/拆短句；不新增虚假经历，受保护稿不自动润色 | NOT_TESTED |
| 视听表达 | 场景用途能在素材/编辑中追溯；使用实测音轨与可用区间，不伪造同现场或试听；视觉局部改动保护声音 | NOT_TESTED |
| 事实与反馈 | 用户提供不等于已核验；判断/引文分清；观察不足不判通过；作品接受不自动变为导演接受或长期记忆 | NOT_TESTED |
| 路径与综合回归 | 新片、改稿、局部修订、自主/固定时长及受影响已有路径；同一受测候选版本的必要正反例、回归和接线 | NOT_TESTED |
| 真实质量与使用成本 | 固定变量分别比较P1/P2，再验证完整版本；审听/观看范围、人工改动、调用费用与耗时可追溯 | NOT_TESTED；未授权调用 |
| 交付与切换 | 固定源码/构建/配置及视图版本，旧任务兼容、部署验证与可执行回退说明，不改原业务断点 | NOT_TESTED；未授权部署 |

具体素材语义例子与对照方法见方案§10。版本整体实现不妨碍统一调试时分开验证变量；模型随机性或无法隔离的变化须明确，单样本不外推长期稳定。

## 调试、交付与完成条件

- **实现完成**：P1、P2-A～D全部具备接线和基础测试，必要权威文档同步，固定候选版本；不能凭P1完成关闭父任务。
- **软件通过**：统一回归与身份/恢复/语义矩阵通过，范围内软件阻断闭环，记SOFTWARE_PASS。缺陷按首次失败记录预期/实际、原因、修复与回归；修复后继续原场景及剩余验收。
- **真实验证与接受**：在相应授权内完成受影响真实环节和完整接线，分别记录REAL_PRODUCTION_PASS与CREATOR_ACCEPTED；完整音画仍按实际观察能力及人工审阅取证。无授权时离线交付但父版本PARTIAL，未测不记PASS。
- **版本完成**：约定范围全部交付，矩阵有证据/结论，阻断处理完成，相关真实质量与用户接受具备证据，交付及兼容回退说明齐备；不要求固定数量试片或“AI味清零”。发布到视频平台不作为软件验收默认动作。
- **隔离与切换**：版本规划不改变当前分支。开发前依最新分支授权记录隔离方案，保护既有Dirty与生产数据；V2.1不自动部署到当前V2。回退不删除媒体/请求、不降级业务库、不重复UNKNOWN。
