- 范围：完成后引导、接受到发布草稿、版本/账号/确认绑定、复用发布/读回与异常恢复。方案推荐先单平台，平台和账号尚待决定；多平台实施、定时运营、归因等不自动纳入。

## 建议完成条件与当前停止边界

第1～4项待范围评审后确认或裁剪；第5项为本次已明确限制。超出首批平台的场景仅按适用范围做离线保护/兼容验证，不因此扩为多平台真实发布。

1. 完成引导按方案§3.1适配合格成片、manual、已知失败、UNKNOWN、已接受及发布待核实；动作与版本一致，不自动发起副作用。
2. 作品接受、导演接受、长期保存与发布授权各自独立；已接受版本可准备发布，编辑/媒体/账号变化使旧发布确认失效。
3. 复用原发布能力及真实读回结果；成功项不重发、未知不盲推、投稿/审核/公开/平台草稿区分，日志失败不重复发布。
4. 经用户确定的首批范围通过适用软件、部署及真实验收，具名证据关联本卡；未验证平台和真实项不写PASS。
5. 仅方案交付或某子项软件通过不能关闭本父任务。当前在待评审处停止，不修改代码、重载、迁库、调用付费服务或真实发布。
