## 1. 执行目标与最小上下文

对照已经核实的 OpenMontage、Instructor、Temporal 实现，沿 Easel 当前代码核对选材、报告交付、失败分类、缓存复用、断点恢复、必要/偏好判断以及后期表达传递。区分已经完成的修复与仍可复现的缺口，只对后者实施最小软件优化。终点为 **有证据、通过确定性验证、可审查和可合并的软件交付**；没有新的缺口时可以交付具名核对结论，不为任务数量另建机制。

默认读根 AGENTS.md、DOCUMENT_INDEX、00_PROJECT、02_CURRENT_STATE、03_ROADMAP，再读本文件。参考实现与固定提交按需读[已完成的 GitHub 研究 §13.2–§13.4](creation-latency-completed-2026-10-05.md#132-github-证据与选型结果)。触及 Creation/Authoring 边界读 ADR-001 与当前视频架构，触及素材职责读 Material V1.3 / ADR-004。Hypit 改动核对实际安装版本及真实源码。

不把已经修复的模型截断、原文编号、偏好误拒、生成接续等重复列为新开发成果；新缺口须有当前源码、失败现场或确定性回放支持。

## 2. 工作范围

| 环节 | 核对与允许的小范围优化 | 风险保护 |
|---|---|---|
| 选材/观察 | 相关小批、按缺口继续、已合格就停止、复用有效观察；有回放证据才改排序 | 不改冻结 required、额度或为 desired_options 继续耗费；不增加 CLIP/向量库 |
| 报告交付 | 固定 ID/原文位置由程序绑定；模型交语义判断；区分截断、结构错误、语义歧义和缺素材 | 不把报告故障转为搜索/生成；不绕过 OpenClaw 直接调用 Provider |
| 重试/恢复 | 单一已有 bounded retry 计数、终态 runId 接续、成功结果保留、未知执行对账 | 不叠加 SDK 内部重试；不重新付费生成或清零累计账本 |
| 意图与后期表达 | 偏好保持软项；必须真实发生的动作保持必要；静态镜头运动/字幕表达按 postproduction 传递 | 不把源素材真缺失伪装成后期完成；不扩大模型权限或改 Material Domain |
| 用户进度 | 既有页面/接口展示真实未覆盖 Need、原因与成果 | 不靠乐观状态冒充 MATERIAL_READY，不重建工作区界面 |

优先复用已存在的实现；OpenMontage 参考选材与职责分配，Instructor/Temporal 参考错误分类与有界恢复。移植小组件前比较重叠并记录仓库、commit、文件、改动和许可。OpenMontage 的 AGPL 义务按总顺序落实；不移植其已发现过宽的最终质检标准。

## 3. 执行与验收

1. 先记录调用链、已实现行为和具名剩余风险，列出这一轮真正需要修改的文件与合同；跨模块合同/职责变更按 AGENTS.md 前置复核，不擅自改变冻结设计。
2. 只修本轮已证明的缺口；重用现有 source→Need/rank、共享观察、生成绑定和恢复记录，不创建另一条制作主链或工作流框架。
3. 用固定输入和确定性执行器验证：偏好不升级为必要项；必要主体/真动作缺失仍拒绝；证据不清仍 unknown；后期承担项正确传递；截断/错号/结构错误不变成素材缺口；有效成功结果在中断和恢复后仍被复用。
4. 同一输入记录改动前后的候选提名、观察调用、恢复步数与重复工作；已有冻结限额不扩大。局部调用减少不等于整片真实耗时改善，没有同环境基线就不报提速比例。
5. 跑风险相关回归和必要组合检查，后期/Hypit 边界用安装版本支持的合同和本地确定性样例核对。按需 lint/build；不调用付费 AI、生成素材或真实 Production Build。
6. 交付可审查的独立分支 Diff、具名软件验证记录和后续真实验收清单。标记没有验证的真实语义/感知能力，不以 fixture 通过声明稳定成片。
